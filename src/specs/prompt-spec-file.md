# Prompt Specification
Read this prompt section by section. 

## The Prompt
Research about Caco-2 Cell Permeability. Then, retrieve TDC's Caco2_Wang dataset and perform machine learning predictions. Return the results of the predictions and explain it in the report.


## Prompt Response Instruction
- Below outlines how you should write the report.

### Report Constraints
1. Word Count without section headers: 
    - Not more than 2000 words
2. Fontsize: 
    - #: For Report Title
    - ##: For Sections
    - ###: For Sub-Sections
    - ####: For bulletpoint list, numbered list, or any sections smaller than Sub-Sections
3. Citation Format:
    - IEEE

### Report Structure
1. Contents Page: This represents the Content Page of the report.
2. Introduction: This should give an overview of the report. A summary of each section should be written here, including conclusion.
3. Content Body: This represents the primary topic that the prompt seeks. It should be split into several sections to provide a guiding experience for the reader. An example of this would be to funnel the depth of topic progressively. One of the sections should explicitly cover example use-cases.
4. Conclusion: This represents the summary for the above sections. Write this section in a way that inspires readers to continue seek knowledge about the topic
5. Citations: This represents the list of citations used in Section 1 and 2.

### Report Output
- Export this report as an .md file
